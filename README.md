# Customer-Data-Analysis
Customer Data Analysis using Power BI
Customer Data Analysis using SQL & Power BI

**1. Project Overview**
Customer Data Analysis is a data analytics project focused on understanding customer shopping behaviour, purchasing patterns, and sales performance across 10 shopping malls in Istanbul, Turkey, during the period 2021–2023.
The main purpose of this project is to analyze customer transactions, identify shopping trends, understand customer preferences, and generate meaningful business insights using SQL and Power BI.
This project transforms raw shopping transaction data into meaningful insights through data analysis, visualization, and interactive dashboards.

**2. Project Objectives**
- To understand customer shopping behaviour and purchasing patterns.
- To analyze customer distribution based on gender and age groups.
- To identify popular product categories.
- To evaluate sales performance and total revenue.
- To analyze different payment methods used by customers.
- To understand shopping trends across different malls.
- To create an interactive dashboard for better business decision-making.
- To generate useful insights and business recommendations.

**3. Dataset Description**
The project uses shopping transaction data collected from 10 shopping malls in Istanbul, Turkey, covering the years 2021 to 2023.
The dataset contains information about customers, purchases, product categories, prices, quantities, payment methods, invoice dates, and shopping mall locations.

**5. Project Workflow**
The project was completed through the following stages:
1. **Data Collection:** Obtained the customer shopping transaction dataset.
2. **Data Understanding:** Explored the dataset and understood its columns and structure.
3. **Database Setup:** Created the database and tables using MySQL Workbench.
4. **SQL Analysis:** Executed SQL queries to retrieve, filter, group, and analyze customer transaction data.
5. **Data Visualization:** Used Power BI to create meaningful charts and visual representations.
6. **Dashboard Development:** Designed an interactive dashboard with KPIs, charts, and filters.
7. **Insights Generation:** Identified important customer behaviour and sales patterns.
8. **Documentation:** Prepared project insights and presentation.
9. **Final Submission:** Organized project files, screenshots, presentation, and dashboard into a ZIP file.

**B. Gender Analysis**

**F. Sales Performance Analysis**
